# ATM Driver for Plusplusland

Plusplusland uses a currency called the plussar. The central bank issues banknotes in values:

- 50 plussar
- 20 plussar
- 10 plussar
- 5 plussar
- 1 plussar

## Task

Write a driver for the ATMs of Plusplusland that delivers any requested amount using the minimal number of banknotes. The ATM should print all required banknote values in a row, separated by spaces.

## Example

For an input of `93`, the output should be:

```
50 20 20 1 1 1
```

## File

- `atm.cpp`: C++ solution implementing the minimal banknote driver.
